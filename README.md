# 🏭 Sistema de Gestão - Fábrica de Software

Sistema simples desenvolvido em Python para representar e controlar o fluxo de produção de uma Fábrica de Software.

## 📌 Objetivos
- Visualizar as etapas de desenvolvimento de cada projeto.
- Controlar responsáveis, entradas (requisitos) e saídas (entregáveis).
- Atualizar o status e progresso do sistema no fluxo da fábrica.

## 🚀 Como Executar
1. Certifique-se de ter o Python instalado (versão 3.6 ou superior).
2. Abra o terminal na pasta do arquivo e execute:

```bash
python fabrica.py
